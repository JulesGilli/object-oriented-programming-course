## Les délégués

Un **délégué** est un type qui représente une **signature de méthode**. Une variable de ce type peut référencer n’importe quelle méthode compatible, et l’appeler plus tard.

```csharp
public delegate int Operation(int a, int b);   // « toute méthode (int, int) → int »

static int Additionner(int a, int b) => a + b;
```

```csharp
Operation op = Additionner;     // on stocke la méthode, sans l’appeler
Console.WriteLine(op(3, 4));    // 7

op = (a, b) => a * b;           // une lambda : une méthode anonyme écrite sur place
Console.WriteLine(op(3, 4));    // 12
```

### `Action` et `Func` : les délégués prêts à l’emploi

Plutôt que de déclarer un type délégué pour chaque signature, on utilise presque toujours les délégués génériques du framework :

| Délégué | Signature | Exemple |
| --- | --- | --- |
| `Action` | aucun paramètre, pas de retour | `Action sauter = () => …;` |
| `Action<T1, …>` | paramètres, pas de retour | `Action<string> journal = message => …;` |
| `Func<TResult>` | aucun paramètre, un retour | `Func<int> lancerDe = () => …;` |
| `Func<T1, …, TResult>` | paramètres et un retour (le **dernier** type) | `Func<int, bool> estPair = n => n % 2 == 0;` |
| `Predicate<T>` | équivalent de `Func<T, bool>` | utilisé par `List<T>.Find` |

```csharp
Action<string> journal = message => Console.WriteLine($"[LOG] {message}");
Func<int, bool> estPair = n => n % 2 == 0;

journal("Démarrage");            // [LOG] Démarrage
Console.WriteLine(estPair(10));  // True
```

## Les expressions lambda

Une lambda s’écrit `(paramètres) => expression` ou `(paramètres) => { instructions }`. Les types des paramètres sont presque toujours **déduits**.

Elles sont omniprésentes avec **LINQ**, où chaque opération reçoit un petit comportement en paramètre, comme une stratégie :

```csharp
var vivants = ennemis
    .Where(e => e.PointsDeVie > 0)     // filtre
    .OrderBy(e => e.PointsDeVie)       // tri
    .Select(e => e.Nom);               // projection

Console.WriteLine(string.Join(", ", vivants));   // Troll, Orc
```

*(avec un Gobelin à 0 PV, un Orc à 45 PV et un Troll à 12 PV)*

### Les captures (*closures*)

Une lambda peut utiliser les variables locales qui l’entourent. Elle les **capture** : elle garde un lien vers la **variable**, pas une copie de sa valeur au moment de sa création.

```csharp
int bonus = 5;
Func<int, int> ajouterBonus = degats => degats + bonus;
bonus = 100;
Console.WriteLine(ajouterBonus(10));   // 110, et non 15 : c’est la valeur au moment de l’appel qui compte
```

Le piège classique, dans une boucle `for` :

```csharp
var actions = new List<Action>();
for (int i = 0; i < 3; i++)
    actions.Add(() => Console.Write($"{i} "));

foreach (var a in actions) a();   // 3 3 3 : les trois lambdas partagent la même variable i
```

Correction : copier la valeur dans une variable locale à la boucle.

```csharp
for (int i = 0; i < 3; i++)
{
    int copie = i;                 // une nouvelle variable à chaque tour
    actions.Add(() => Console.Write($"{copie} "));
}
// 0 1 2
```

> [!NOTE]
> Depuis C# 5, la variable d’une boucle **`foreach`** est recréée à chaque tour : le piège ne concerne que la boucle `for`.

## Les délégués multicast

Un délégué peut référencer **plusieurs méthodes** : on les ajoute avec `+=`, on les retire avec `-=`, et un seul appel les exécute toutes, dans l’ordre d’ajout.

```csharp
Action salut = () => Console.WriteLine("Bonjour");
salut += () => Console.WriteLine("Au revoir");
salut();
```

**Sortie :**

```
Bonjour
Au revoir
```

C’est exactement le mécanisme d’abonnement du pattern **Observer**.

## Les événements (`event`)

Un **événement** est un délégué multicast **protégé** par le mot-clé `event` :

```csharp
public class Minuteur
{
    public event Action OnTermine;     // l’extérieur peut seulement faire += et -=

    private void Terminer()
    {
        OnTermine?.Invoke();           // seule la classe qui déclare l’événement peut le déclencher
    }
}
```

| Depuis l’extérieur de la classe | Champ `public Action` | `public event Action` |
| --- | --- | --- |
| S’abonner (`+=`) / se désabonner (`-=`) | ✅ | ✅ |
| Déclencher (`minuteur.OnTermine()`) | ✅ (dangereux) | ❌ |
| Écraser tous les abonnés (`= null`) | ✅ (dangereux) | ❌ |

L’opérateur `?.` évite une `NullReferenceException` quand personne n’est abonné. Le pattern complet est détaillé dans la fiche [7. Observer](<../../Chapitre 2/Partie III — Patterns Comportementaux/7. Observer.md>).

## Dans Unity

* **`UnityEvent`** est l’équivalent sérialisable d’un événement C# : on peut y brancher des méthodes **depuis l’Inspector**, comme le `onClick` d’un `Button`. Il est plus lent qu’un `event Action`, mais pratique pour les designers.
* **Abonnement par code :** `bouton.onClick.AddListener(() => Debug.Log("Clic"));`
* **Lambdas et allocations :** une lambda qui capture une variable alloue un objet. Créer des lambdas à chaque frame dans `Update()` génère du travail pour le ramasse-miettes et peut provoquer des saccades.
* **Désabonnement :** comme pour tout événement, se désabonner dans `OnDisable()` ou `OnDestroy()`.

> [!WARNING]
> **On ne peut pas se désabonner d’une lambda écrite en ligne.**
> ```csharp
> bouton.onClick.AddListener(() => Tirer());
> bouton.onClick.RemoveListener(() => Tirer());   // ❌ sans effet : c’est une AUTRE lambda
> ```
> Pour pouvoir se désabonner, il faut garder une référence vers le délégué, ou s’abonner avec une méthode nommée :
> ```csharp
> bouton.onClick.AddListener(Tirer);
> bouton.onClick.RemoveListener(Tirer);           // ✅
> ```

## ⚠️ Pièges courants

* **Capturer une variable de boucle `for`** dans une lambda (voir plus haut).
* **Oublier le `?.`** avant `Invoke()` : `NullReferenceException` quand personne n’écoute.
* **Oublier de se désabonner** : l’objet qui déclenche garde une référence vers l’abonné, qui ne peut plus être libéré (et, dans Unity, des appels sur des objets détruits).
* **Exposer un champ délégué public** au lieu d’un `event`.

## 🔀 À ne pas confondre

* **Délégué** (un *type* qui décrit une signature) et **événement** (un *membre* de classe, de type délégué, protégé par `event`).
* **Lambda** (une syntaxe pour écrire une méthode sur place) et **délégué** (le type de la variable qui la reçoit).

## 🧪 Exercice : le minuteur

Écrivez une classe `Minuteur` :

* son constructeur reçoit un nombre de secondes ;
* elle expose deux événements : `OnSecondeEcoulee` (`Action<int>`, reçoit les secondes restantes) et `OnTermine` (`Action`) ;
* sa méthode `AvancerUneSeconde()` décrémente le compteur, déclenche `OnSecondeEcoulee`, puis `OnTermine` quand on arrive à zéro. Une fois à zéro, elle ne fait plus rien.

**Contrainte :** le test doit pouvoir se désabonner de `OnSecondeEcoulee` après le premier tick.

**Test attendu :**

```csharp
var minuteur = new Minuteur(3);
Action<int> afficher = s => Console.WriteLine($"Il reste {s} s");
minuteur.OnSecondeEcoulee += afficher;
minuteur.OnTermine += () => Console.WriteLine("Boum !");

minuteur.AvancerUneSeconde();
minuteur.OnSecondeEcoulee -= afficher;      // fonctionne : même instance de délégué
minuteur.AvancerUneSeconde();
minuteur.AvancerUneSeconde();
minuteur.AvancerUneSeconde();     // déjà terminé : rien ne se passe
```

```
Il reste 2 s
Boum !
```

<details>
<summary>Voir la solution</summary>

```csharp
public class Minuteur
{
    private int secondesRestantes;

    public event Action<int> OnSecondeEcoulee;
    public event Action OnTermine;

    public Minuteur(int secondes) => secondesRestantes = secondes;

    public void AvancerUneSeconde()
    {
        if (secondesRestantes == 0)
            return;

        secondesRestantes--;
        OnSecondeEcoulee?.Invoke(secondesRestantes);

        if (secondesRestantes == 0)
            OnTermine?.Invoke();
    }
}
```

Le désabonnement fonctionne parce que la lambda est stockée dans la variable `afficher` : `+=` et `-=` reçoivent la même instance de délégué.

</details>

## ✅ Récap

| Notion | Exemple |
| --- | --- |
| Délégué personnalisé | `delegate int Operation(int a, int b);` |
| Délégués standards | `Action<T>`, `Func<T, TResult>` |
| Lambda | `n => n % 2 == 0` |
| Multicast | `salut += autreMethode;` |
| Événement | `public event Action<int> OnSecondeEcoulee;` |
| Déclenchement sûr | `OnSecondeEcoulee?.Invoke(valeur);` |
